# Telegram ChatGPT Concierge Bot Brand

The Telegram ChatGPT Concierge Bot is a conversational assistant for text and
voice messages. It transcribes voice, answers requests, and can return a spoken
reply. Describe these capabilities plainly.

## Name

Use `Telegram ChatGPT Concierge Bot` when naming this repository. The shorter
word `bot` is suitable after the full name is clear. Do not present the demo
instance name or avatar as a canonical product identity.

## Voice

- Use brief, friendly, and direct messages.
- State the completed action before extra detail.
- Label transcribed text with `Transcription:`.
- Explain validation problems and the next valid action.
- Name a failed service only when that helps the user recover.
- Admit uncertainty instead of inventing an answer.

## Experience

Text requests receive text answers. Voice requests receive a transcription,
an answer, and an optional voice reply. Use Telegram’s typing state while work
is in progress. Keep system messages separate from generated answers.

## Attribution and boundaries

Preserve the upstream author attribution in the README. Telegram owns the chat
interface shown in the demo. OpenAI, LangChain, Play.ht, Google, and Railway are
third-party names. Do not treat their colors, icons, or marks as this
repository’s brand.

Never include access tokens, message contents, user identifiers, or service
logs in public brand examples.
